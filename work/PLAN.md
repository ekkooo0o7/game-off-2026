# Preparation plan

## Confirmed

- GitHub Game Off 2026 theme: SHIFT.
- Official submission deadline: December 1, 2026, 13:37 PST, which is December 2, 2026, 05:37 in China Standard Time (UTC+8).
- Voting ends January 1, 2027, 13:37 PST.
- A qualifying entry needs both a public GitHub source repository and a separate itch.io jam submission. A repository push alone does not submit the game.
- Any engine and AI assistance are allowed; the submission asks participants to disclose AI use.
- Main development must happen during the jam. This repository is only a starter and planning shell; no finished game or prebuilt mechanics are being carried in.

## Chosen setup

- Browser-first delivery to reduce friction for voters.
- Plain HTML, CSS, and JavaScript starter with no runtime dependencies.
- Keep source here; keep planning notes and local capture material under `work/`; keep candidate builds and showcase media under `outputs/`.
- Aim for a complete playable slice before expanding scope.

## Still undecided

- Game title and interpretation of SHIFT.
- Core mechanic and level design.
- Final art and audio direction.
- Itch.io entry page details and jam membership confirmation.

## Working timeline (China Standard Time)

- Nov 17–19: choose one concept and prove its core loop.
- Nov 20–25: build one polished playable level and essential feedback/audio.
- Nov 26–28: accessibility, balance, browser checks, capture screenshots and a short trailer.
- Nov 29–30: package and test the itch.io build; finish README and AI disclosure.
- Dec 1: internal target for submission and final checks.
- Dec 2, 05:37: official cutoff; do not plan work up to the final minute.

This schedule compresses the proposed phases because development is already underway. Cut scope before cutting verification or submission time.
