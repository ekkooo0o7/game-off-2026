# Submission checklist

## Before the deadline

- [ ] Confirm itch.io shows the account has joined Game Off 2026.
- [ ] Commit and push the complete source to this public repository.
- [ ] Export a playable browser build and test it from a clean browser session.
- [ ] Publish the game page on itch.io and set the browser build to playable in browser.
- [ ] Separately submit the published game page to the Game Off 2026 jam.
- [ ] Verify the jam entry is visible in the jam's submissions list.
- [ ] Add controls, build/run instructions, and asset/license credits to README.
- [ ] Disclose AI assistance accurately in the submission and README.
- [ ] Add a cover image and screenshots; capture a short gameplay clip if time allows.
- [ ] Finish at least one day before the official deadline where possible.

## After submission

- [ ] During voting, play and review other qualifying entries.
- [ ] Keep the submitted build stable while fixing only critical issues.
